# React Interactive Tabs

A clean and interactive Tabbed Interface built with React. This project demonstrates how to manage component states to switch between different content blocks dynamically based on user interaction.

# Features
Dynamic Content Rendering: Content is passed as an array of objects and rendered based on the active tab index.

State-Driven UI: Uses React useState to track the active tab and update the view instantly.

Reusable Component Architecture: The core logic is encapsulated in a Tabbed component, making it easy to drop into any project.

Clean Data Structure: Content is managed through a structured array, allowing for easy updates and scalability.

# Tech Stack
Framework: React (Functional Components)

State Management: React useState Hook

Styling: CSS Modules / CSS3

Language: JavaScript (ES6+)
